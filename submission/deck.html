Readback / The product04 / 10+
01 · Hear

You say it.

AssemblyAI Voice Agent API

One WebSocket: speech, turn detection, tool calling, voice. The agent records your intent as a strict schema through a tool call. It never sees the transaction, so it can’t be talked into agreeing with it.

02 · Decide

Rules check it.

Notary · @readback/core

Decodes the real calldata server-side, unpacks router multicalls and Safe MultiSend batches, checks every address on Base. 27 deterministic rules. Every finding names its rule. No model decides.

03 · Enforce

The chain refuses.

ReadbackGuard · Safe guard

A match on a Safe yields an EIP-712 attestation over the exact Safe tx hash. The guard refuses any transaction without one. Owner signatures alone are no longer enough.

Readback / Measured, not claimed08 / 10+
What measuring caught

We were wrong, then we measured.

100%false positives from our first “always block DELEGATECALL” rule on 81 real Base Safe txs. All went to Safe’s own MultiSend. Now unpacked: 77/77 real batches decode.
38.7%of active Safes sent only transactions an open decoder could read. For the rest: “I can’t read this. Don’t sign something nobody can read.”
12msnotary latency, down from 2,187 ms, by fetching chain facts while you’re still speaking.
